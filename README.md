# Hill Climb Racing 2 - Port Nativo ARM64 para R36S (ArkOS Linux)

Port nativo aarch64 do jogo **Hill Climb Racing 2 (v1.28.2)** executado diretamente no hardware do console portátil R36S via SDL2, OpenGL ES 2.0 (Mali-G31) e OpenSL ES.

## 🎮 Mapeamento de Controles no R36S
- **Navegação de Menus**: Analógico Direito (Stick R) movimenta o cursor virtual com fade suave.
- **Seleção / Clique**: Botão **B** (com trava de posição anti-swipe).
- **Aceleração**: Botão **A**, **R1**, **R2** ou **D-Pad Direita**.
- **Freio / Ré**: Botão **Y**, **L1**, **L2** ou **D-Pad Esquerda**.
- **Turbo / Boost**: Botão **X**.
- **Atalho de Saída**: Pressione **SELECT + START** para sair graciosamente com gravação de progresso.
- **Menu Overlay**: Pressione **SELECT + X**.
